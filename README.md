# Redis Manager

Desktop app to start and stop a local Redis server interactively (egui).

The Redis Windows runtime is **embedded in the `.exe` **. On first launch it is extracted **next to the executable** ( `runtime/redis/` ), so you can distribute a single binary as a portable app.

## Requirements

* Rust stable (`rustup`)
* On Windows GNU toolchain: MinGW-w64 on `PATH` (also used by `build.rs` for the app icon via `windres`)

## Build & run

```powershell
cargo build
```

Release build:

```powershell
cargo build --release
```

Binary output: `target/debug/redis-manager.exe` or `target/release/redis-manager.exe` .

## Portable layout

After the first run, files beside the exe look like:

```text
redis-manager.exe
.env                       # ENABLE_UPDATE_CHECK=true|false
theme.json                 # theme preference (system | light | dark)
update.json                # dismissed GitHub release version (Later)
runtime/redis/             # extracted Redis runtime
  redis-server.exe
  redis.conf
  ...
autostart.log              # only when started with --autostart
```

## Updates

Toggle in-app update checking via `.env` (project root for `cargo run` , or beside the `.exe` when packaged):

```env
ENABLE_UPDATE_CHECK=true
```

Default is `false` . When enabled, the app checks [GitHub Releases](https://github.com/Pepeqi-Esport-Reborn/redis-manager/releases) on startup and via **Check update** in Settings.

* **Later** stores that remote version in `update.json` so the same release is not auto-prompted again; a newer release prompts again.
* Manual **Check update** always reports status and can offer Update even for a dismissed version.

## Features

* Start / stop local Redis (`127.0.0.1:6379`)
* Live status + overview cards (BeAced-style dark/light UI)
* Inter UI typeface
* Theme: System / Light / Dark (saved in `theme.json` beside the exe)
* Launch on startup (Windows Run entry via `redis-manager.exe --autostart`)
* In-app updates (GitHub Releases)
* Single-exe distribution (embedded Redis runtime + DLLs)
* App branding from `assets/images/logo/logo.png` (`logo-256.png` + Windows icon generated by `build.rs`)
