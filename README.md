# Redis Manager

Desktop app to start and stop a local Redis server interactively (egui).

The Redis Windows runtime is **embedded in the `.exe`**. On first launch it is extracted **next to the executable** (`runtime/redis/`), so you can distribute a single binary as a portable app.

## Requirements

- Rust stable (`rustup`)
- On Windows GNU toolchain: MinGW-w64 on `PATH` (also used by `build.rs` for the app icon via `windres`)

## Build & run

```powershell
cargo build
```

Release build:

```powershell
cargo build --release
```

Binary output: `target/debug/redis-manager.exe` or `target/release/redis-manager.exe`.

### Windows release (6 artifacts)

Produces portable + installer for x64, x86, and ARM64 under `dist\`:

- `redis-manager-{version}_portable_windows_64.exe`
- `redis-manager-{version}_portable_windows_86.exe`
- `redis-manager-{version}_portable_windows_arm64.exe`
- `redis-manager-{version}_installer_windows_64.exe`
- `redis-manager-{version}_installer_windows_86.exe`
- `redis-manager-{version}_installer_windows_arm64.exe`

Requires **Rust MSVC** targets (`x86_64`, `i686`, `aarch64`), Visual Studio **ARM64** build tools for cross-compile, and [Inno Setup 7](https://jrsoftware.org/isinfo.php) (6 also works).

```powershell
cargo release
```

Or:

```powershell
.\scripts\build-installer.ps1
```

Run `cargo build` once first so `installer\app.ico` is generated from the logo.

## Portable layout

After the first run, files beside the exe look like:

```text
redis-manager.exe
config.json                # app config (theme: system | light | dark)
runtime/redis/             # extracted Redis runtime
  redis-server.exe
  redis.conf
  ...
autostart.log              # only when started with --autostart
```

## Features

- Start / stop local Redis (`127.0.0.1:6379`)
- Live status + overview cards (BeAced-style dark/light UI)
- Inter UI typeface
- Theme: System / Light / Dark (saved in `config.json` beside the exe)
- Launch on startup (Windows Run entry via `redis-manager.exe --autostart`)
- Single-exe distribution (embedded Redis runtime + DLLs)
- App branding from `assets/images/logo/logo.png` (`logo-256.png` + Windows icon generated by `build.rs`)
